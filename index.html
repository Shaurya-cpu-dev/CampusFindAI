HOW IT WORKS • SIMPLE, NOT TECHNICAL

Report. Compare. Notify.

No complicated forms. We only ask what actually helps find a match.

1

Report what happened

Lost: item, where, when, short description, optional photo. Found: same. Takes ~30 seconds.

2

We compare reports

CampusFind compares your report with others using AI that looks at item type, description, location and time.

3

You get notified if possible match

If we spot a likely match, the owner gets a private notification. No emails shown publicly.

Privacy: Lost reports are private and linked to your account. Found reports create a generic campus alert like “A lost item has been found!” without revealing details. Possible matches are only visible to the owner.

Honesty: We show possible matches, not guarantees. You decide if it's yours.
